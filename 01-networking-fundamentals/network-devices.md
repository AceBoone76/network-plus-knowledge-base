# Network Devices

## Overview

Network devices are hardware devices that allow computers and other devices to communicate with each other and access network resources.

## Common Network Devices

### Router

A router connects different networks and determines where network traffic should go.

Example:

My home router connects my home network to the Internet.

### Switch

A switch connects devices within a local network.

Example:

A switch can connect computers, printers, servers, and other wired devices within a home or business network.

### Wireless Access Point

A wireless access point allows wireless devices to connect to a wired network.

### Firewall

A firewall controls network traffic based on security rules.

It can allow or block traffic based on factors such as:

- Source IP address
- Destination IP address
- Port
- Protocol
- Application

## Real-World Example

A typical home network may work like this:

Internet
↓
Router/Firewall
↓
Network Switch
↓
Computers and other wired devices

Wireless devices connect through a wireless access point.
